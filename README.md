One line, the most useless superpower imaginable, written by `main.py`
to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output`).

## Run

```sh
python3 main.py
```

## Entry

> I can summon any object I want, but it arrives by standard shipping in 6 to 8 weeks.
